## About

I'm a backend engineer in Dhaka, Bangladesh, specializing in **Java and Spring Boot**. Most of my work lives in distributed systems — a **10+ service microservices ecosystem**, an enterprise **MDM platform managing 120,000+ devices**, and a **Java 21 search service** running dynamic queries across SQL and OpenSearch.

Day to day that means designing REST APIs, wiring up Kafka-based event-driven flows, writing reactive code with Spring WebFlux, and keeping services resilient with Resilience4j circuit breakers and distributed locking.

- **Currently at** atB Lab Limited, building backend services for Japanese enterprise clients
- **Recently** contributed to a **Java 21 → Java 25 migration** — resolving compatibility issues, updating dependencies and build configs, verifying application and test stability
- **Working toward** AWS Certified Solutions Architect – Associate
- **Education** MSc & BSc in Computer Science & Engineering — Jahangirnagar University, AIUB
- **Open to** Senior Backend Engineer roles — Dhaka, remote-first, and international teams

## Selected Work

**PORTERS Search Core** — Java 21 REST search service
Dynamic query execution across SQL databases and OpenSearch, through a pipeline of query parsing, optimization, analysis, strategy selection, and backend-specific execution. Also built TypeScript/Jest black-box E2E test suites covering positive and negative search scenarios across multiple resources and condition types.
`Java 21` `Gradle` `OpenSearch` `Docker` `Dev Containers` `AWS ECR` `JUnit` `Jest`

**Dream Emirates** — 10+ service microservices ecosystem
Maintained and enhanced services spanning User Profile, Wallet, Subscription, IAM, Billing, Gateway, and Financial Account domains. Built Kafka-based event-driven communication, reactive non-blocking flows with WebFlux, and AWS CodePipeline/CodeBuild/ECR CI/CD workflows.
`Spring WebFlux` `Kafka` `PostgreSQL` `MongoDB` `Redis` `Docker` `AWS`

**CRMS — Prime Bank** — Collection & Recovery Management System
REST APIs for loan, recovery, and collection modules in a microservices architecture, with service-to-service communication via OpenFeign and WebClient, and query optimization on PostgreSQL.
`Spring Boot` `Microservices` `OpenFeign` `PostgreSQL`

**MobiManager** — Enterprise Mobile Device Management
RESTful APIs for device policies, remote actions, and app installations across **120,000+ managed devices**. Integrated the Android MDM Agent App with the Spring Boot backend for real-time device management, content sharing, and instant notifications.
`Spring Boot` `Spring Security` `MySQL` `Android Management API` `FCM` `Google Pub/Sub`
